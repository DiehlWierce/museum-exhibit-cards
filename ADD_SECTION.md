# Как добавить новый раздел вручную

Сайт остаётся обычным набором HTML, CSS и JavaScript. Новый раздел можно добавить тем же способом, которым добавлялись предыдущие: скопировать раздел и карточку, затем заменить содержимое.

1. Скопируйте папку похожего раздела в корень репозитория и задайте ей постоянный короткий адрес, например `new-section-slug`. Сделайте это до печати QR-кодов.
2. В скопированной папке оставьте одну карточку-заготовку и переименуйте её папку, например в `new-card-slug`.
3. Замените в `index.html` раздела заголовок и пункты меню в `script.js`.
4. На главной странице добавьте раздел в массив `folders` файла `script.js`.
5. В карточке замените заголовки, изображение, аудио и текст. Сохраните блок `qrcode` и подключения общих CSS/QR-файлов.
6. Скопируйте папку карточки для остальных объектов и обновите содержимое каждой копии. Адрес карточки задаётся путём `имя-раздела/имя-карточки/index.html`.
7. Когда карточки готовы, зарегистрируйте их QR-адреса и проверьте весь реестр:

   ```sh
   python3 scripts/check_qr_routes.py --register-new
   python3 scripts/check_qr_routes.py
   ```

   Первая команда добавляет новые страницы в `qr-routes.json` и сохраняет все уже зарегистрированные адреса. Она не удаляет старые записи.

Имена зарегистрированных папок карточек после печати QR-кодов не меняйте. Папку раздела тоже не переименовывайте: GitHub Pages включает имя репозитория в основной адрес сайта.
